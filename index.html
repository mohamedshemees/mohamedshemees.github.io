Kmp Resources Unfold

I designed and built Kmp Resources Unfold for Android Studio and IntelliJ IDEA to solve a major friction point in Kotlin Multiplatform (KMP) development. It brings visual asset management directly into the IDE, featuring a dedicated local bridge to import assets from Figma, automatic SVG-to-Android Vector XML conversion, and instant font and string localization previews.

hub Figma Bridge: Direct asset import via local HTTP server
transform SVG to XML: Auto-converts to Vector Drawables
font_download Font Inspector: Waterfall scaling & specimen preview
translate Strings Localization: Missing translation warnings

Branch Peek

Read-Only Real-Time

I created Branch Peek to give developers a faster, non-destructive way to inspect unpushed commits before pushing. It adds a vertical, Commit-tool-window style panel docked on the left that isolates and displays only the exact files scheduled for git push (excluding working tree noise), with instant access to native green (+) and blue (~) Git gutter helpers in the editor.

dock_to_left Docked Side Panel: Commit-style left tool window
filter_alt Clean Diff Scope: Excludes working tree changes
difference Native Gutter Helpers: Real-time green (+) and blue (~) diffs
sync Non-Destructive: 100% read-only & real-time updates
